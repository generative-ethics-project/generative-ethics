# Research strands

These are continuing questions, not separate organisations or permanently diverging Git branches. Contributions share the tenet register, source analyses, work board, and living book. A strand may contain competing arguments.

| Strand | Entry points | Initial work |
|---|---|---|
| Exploration and ethical relations | [Invitation](../INVITATION.md), [tenets](../TENETS.md), [ethical logic](../ETHICAL_LOGIC.md) | W0, W4, W7 |
| Continued learning and information | [Candidate argument](../ARGUMENT.md), [research agenda](../RESEARCH.md) | W1, W2 |
| Human generativity and systems | [Book](../BOOK_OF_EMERGENCE.md), [candidate argument](../ARGUMENT.md) | W3 |
| Mathematical language and proof | [Language brief](../ETHICAL_LOGIC.md) | W6 |
| Comparative deliberation | [Language brief](../ETHICAL_LOGIC.md), actual strand reports as they appear | W8 |
| Custodianship and governance | [Governance brief](../GOVERNANCE.md), [book](../BOOK_OF_EMERGENCE.md) | W5, with ethical dependencies explicit |
| Wider philosophical branches | [Branch map](../BRANCHES.md): religion, universality, simulation, emergence, and replication | Propose a bounded task tied to its question |

Start with [BOARD.md](BOARD.md). Use [the strand brief template](../templates/RESEARCH_STRAND.md) when proposing a new strand or a substantial fork in reasoning. A contribution can link several strands without copying all their material. The [collaboration framework](../COLLABORATION.md) explains coordination and review.
